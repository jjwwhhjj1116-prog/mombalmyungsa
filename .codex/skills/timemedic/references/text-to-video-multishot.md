# 몸의 발명사 Flow 텍스트 투 비디오 멀티샷

## 기본 경로

```text
승인 대본
→ 사실 이중 검수
→ 문장별 대사·장면·감정과 연속성 앵커
→ 2–3개 인접 문장을 한 생성 단위로 묶기
→ 한국어 검수 프롬프트 + 영어 생성 프롬프트
→ 훅·메커니즘/반전 파일럿 두 단위
→ Flow Omni Flash 9:16 후보 생성
→ 좋은 1–3초 수확
→ 최종 TTS 문장 경계에 배치
→ 자막·VOK·정확한 수치 후반 합성
```

이미지 생성은 기본 단계가 아니다. 기록 자료, 반복 캐릭터 정합성, 정확한 공간 도해가 텍스트 투 비디오보다 중요한 예외에만 사용한다.

## 생성 단위

- 40–80초 영상: 10–18개.
- 원본 길이: 8초.
- 샷 수: 2–3개.
- 권장 시간표: `3초+3초+2초` 또는 `4초+4초`.
- 한 클립에 인과적으로 이어지는 문장만 묶는다.
- 샷마다 화면 동사와 카메라 목적이 달라야 한다.
- 훅·반전·복잡한 손동작·인체 내부 메커니즘·연속성 핵심 단위는 후보 두 개, 나머지는 먼저 한 개만 생성한다.
- 후보는 8초 전체의 분위기가 아니라 문장별로 건질 수 있는 정확한 1–3초 행동 수로 고른다.

## 공개 튜토리얼 분석을 프롬프트로 컴파일

모든 Flow 생성 계획은 [reference-channel-flow-grammar.md](reference-channel-flow-grammar.md)의 고수준 문법을 먼저 적용하고 `reference_grammar_lock`을 남긴다. 특정 채널의 장면·대사·워터마크·캐릭터를 복제하지 않고 다음 구조만 몸의 발명사 디오라마 문법으로 번역한다.

1. 현대 결과를 첫 프레임에서 즉시 보여준다.
2. 같은 대상 안으로 들어가 상식의 모순을 매크로 샷으로 질문한다.
3. 실패가 반복되는 물리 행동을 서로 다른 샷으로 누적한다.
4. 반전 직전에는 카메라 이동을 줄이고 의미 대상에 짧게 홀드한다.
5. 질문이 뒤집히는 순간 카메라 축과 대상의 행동을 함께 바꾼다.
6. 해결 뒤 첫 장면과 같은 앵커로 매치컷해 현재로 돌아온다.

`reference_grammar_lock`에 분석 출처 경로, 채택한 고수준 규칙, 복제 금지 확인, 각 생성 단위의 적용 비트를 기록한다. 잠금이 없으면 Flow 컴포저를 열지 않는다.

## 프롬프트 순서

1. 9:16과 시리즈 비주얼 정체성.
2. 실제 사건의 국가·도시 또는 지역·연대·공간·인물 국적을 적은 `setting_contract`. 한국 제품·한국 의학사라면 `Korean` 한 단어로 끝내지 않고 당시 한국의 실내 구조, 복식, 가구, 산업 설비 등 화면에 보일 단서를 최소 세 개 지정한다.
3. `SHOT A/B/C`와 초 단위 구간.
4. 피사체의 실제 행동.
5. 카메라 위치·이동·종료 앵커.
6. 환경의 인과적 반응.
7. 앞 샷에서 이어받을 주 운동 운반체와 다음 샷으로 넘길 종료 속도·화면 위치.
8. 화면에 보이는 물체음·공간음과 금지할 대사·내레이션·음악을 적은 `native_audio_plan`.
9. 정확한 글자를 넣지 않는 빈 표찰·계측판.
10. 랜덤 움직임·립싱크·모핑·고어·생성 글자·무관한 영화식 효과음 금지. 한국 장면에는 서양 약국, 유럽·미국식 술병, 바, 서양 광고 라벨처럼 지리·상품 정체성을 바꾸는 요소도 명시적으로 금지한다.

사람이 검수할 한국어 프롬프트와 Flow에 넣을 영어 프롬프트를 같은 단위에 저장한다. 두 프롬프트의 샷 수, 시간표, 행동, 카메라, 종료 앵커는 의미상 같아야 한다.

## 편집 불변식

- TTS가 시간축의 단일 원본이다.
- 문장 하나는 자기 TTS 구간을 소유한다.
- 한 문장 안에서 1–3개의 컷을 쓸 수 있지만 모두 같은 의미만 강화한다.
- 다음 문장 결과를 미리 보여주지 않는다.
- 8초 원본을 통째로 쓰지 않고 가장 좋은 1–3초만 수확한다.
- 컷은 기본적으로 문장이 끝나는 프레임에서 넘긴다.
- 최종 영상 프레임 수는 `round(final_tts_duration_seconds × fps)`이며 TTS와의 차이는 최대 1프레임이다.
- 자막은 ElevenLabs 또는 강제정렬 결과의 실제 단어 시작·끝 시각을 사용한다. 균등 분할·추정 타이밍은 금지한다.
- 정확한 한글·영문·숫자·연도는 Gmarket Sans Bold 후반 합성만 허용한다.
- 속도를 줄여야 할 때는 대체 후보를 먼저 찾는다. 대체 후보가 없고 좋은 행동 구간이 TTS보다 짧을 때만 광학 흐름을 허용한다.
- 광학 흐름 적용 뒤 손·얼굴·가슴 압박·전극·의료기구의 형태를 프레임 단위로 검사한다.
- 인접 컷은 `motion_carrier`, 방향, 화면 위치, 카메라 축 가운데 최소 둘을 공유한다. 의미가 바뀌면 물체 매치·행동 매치·가림·휩팬·벽 통과로 운반체를 눈앞에서 넘긴다.
- 반전 직전 홀드나 증거 판독을 제외하고 0.7초 넘는 죽은 정지를 금지한다. 새 변화는 평균 1.5–2.5초 안에 오되 다음 문장 의미를 미리 공개하지 않는다.
- 네이티브 오디오는 수확 단계에서 별도 판정한다. 보이는 사건과 ±2프레임, 가짜 말소리·음악 없음, 공간 연속성 통과 시에만 살린다.

## 카메라 문법

- 상황: 와이드 또는 미디엄 시작.
- 과정: 횡이동, 매크로 추적, 물체를 따라가는 카메라.
- 증거·질문·반전: 빠른 푸시인 뒤 6–10프레임 홀드.
- 한 8초 클립의 축 전환은 최대 두 번.
- 느린 줌과 호흡만으로 장면을 채우지 않는다.

## 샘플 게이트

훅 한 단위와 메커니즘 또는 반전 한 단위에서 다음을 확인한 뒤 전체 배치를 허용한다.

- 예정된 2–3개 샷이 순서대로 나오는가?
- 각 샷에서 행동 주체와 의미 대상이 보이는가?
- 다음 문장의 결과가 먼저 나오지 않는가?
- 미니어처 재질·팔레트·렌즈·광원이 유지되는가?
- 생성 글자·중복 팔다리·모핑·공포 표현이 없는가?
- 국가·연대·공간·인물의 `setting_contract`가 실제 프레임에 보이며 다른 문화권의 기본 이미지로 대체되지 않았는가?
- 각 문장에서 사용할 1–3초 구간을 실제로 건질 수 있는가?
- 샷 사이에서 같은 운동 운반체와 방향·위치가 이어져 영상이 흐르듯 보이는가?
- 네이티브 오디오가 보이는 사건에 붙어 있고 대사·음악·무관한 공간음이 없는가?

둘 중 하나라도 실패하면 나머지를 생성하지 않는다. 스타일 프리픽스, 물리 행동, 카메라 종료 앵커, 연속성 계약을 고친 뒤 실패한 파일럿만 다시 만든다.
