## 고정 채널

- 공개 채널명: `몸의 발명사`
- YouTube channel ID: `UCYqdIlpFlB6uh_cpIYgo85g`
- 기본 업로드 경로는 `scripts/youtube_upload_body_invention.py`의 전용 YouTube Data API v3 OAuth 라우트다.
- 몸의 발명사 전용 OAuth 토큰만 사용하고, `channels.list(mine=true)`가 정확히 `UCYqdIlpFlB6uh_cpIYgo85g` 하나를 반환할 때만 파일을 읽고 업로드한다.
- 다른 채널 토큰 탐색·fallback·채널명만 비교하는 검사는 금지한다. 업로드 직후 `videos.list`의 실제 `snippet.channelId`를 다시 검사한다.
- API로 제공되지 않거나 확인할 수 없는 항목만 로그인된 Chrome의 몸의 발명사 채널에서 보완한다. 이때도 입력 전·최종 제출 전·공개 확인 때마다 보이는 채널명과 channel ID를 다시 확인한다.
- OAuth 클라이언트·refresh token·업로드 원장은 `.private/youtube/`에만 두고 Git에 기록하지 않는다. 자세한 연결 절차는 `docs/YOUTUBE-OAUTH.md`를 따른다.

## 제목 패턴

건축·과학 사전형 고조회 영상에서 반복되는 고수준 구조만 사용하고 특정 채널의 문구를 복제하지 않는다.

1. 익숙한 신체·행동·도구를 첫 주어로 둔다.
2. 시청자가 당연하다고 여긴 행동 속 검증된 모순을 붙인다.
3. 가능하면 연도·수치·장소·관찰 장치 중 하나를 넣어 구체화한다.
4. 결말 전체를 말하지 말고 `왜`, `어떻게`, 뜻밖의 실마리 중 하나를 남긴다.
5. 제목의 약속을 첫 프레임과 첫 3초가 실제로 증명해야 한다.
6. `l 건강 l 의학역사` 같은 검색어 나열과 과장된 치료·생존 보장을 금지한다.

후보 제목을 매번 5개 만든 뒤 아래 항목을 각각 5점 만점으로 평가한다.

- 명료성: 한 번 읽고 인물·행동·사건을 이해하는가
- 호기심 간극: 답을 숨기되 질문은 구체적인가
- 검색 관련성: 핵심 의학 용어가 자연스럽게 들어갔는가
- 영상 일치성: 첫 장면과 결정적 행동이 제목을 증명하는가
- 사실성: 인과·시기·의학 효과를 과장하지 않았는가

동점이면 사실성, 영상 일치성, 명료성 순으로 고른다.

## 설명란 패턴

설명은 해시태그를 제외하고 세 문단으로 쓴다.

1. 현재의 익숙한 장면 + 그 안의 물리적·의학적 모순
2. 과거의 막힌 문제 + 결정적 관찰·장치·행동 + 발상의 전환
3. 영상에서 확인할 핵심 + 오늘의 의미 + 필요한 의료 안전 문구

설명 첫 두 줄에는 주제 인물·사건·결정적 행동과 핵심 검색어 1–2개를 자연스럽게 넣는다. 논문 제목을 베끼거나 키워드를 반복하지 않는다. AI 재현 장면이 있으면 `일부 장면은 역사 자료를 바탕으로 AI로 재현했습니다.`라고 밝힌다. 응급처치 소재에는 `실제 응급상황에서는 119 안내와 최신 심폐소생술 지침을 따르세요.`를 넣는다.

설명 마지막에는 주제별 해시태그 4–6개를 우선한다. 사용자가 특정 해시태그 묶음을 명시하면 그 묶음을 정확히 보존하되 제목에는 넣지 않는다.

## 업로드 전 마스터 QA

0. 승인 대본의 실제 최종 TTS가 `180.000초 이하`면 9:16 Shorts, `180.000초 초과`면 16:9 longform인지 `05-duration-route.lock.json`과 최종 MP4 화면비로 대조한다. 경계값 180.000초는 Shorts에 포함한다.

1. 승인된 TTS take와 합성 모델을 기록한다.
2. 채널이 요구한 최대 전달 속도를 적용했는지 확인한다. 원본 합성 속도와 후반 tempo를 구분해 로그에 남긴다.
3. 120ms 이상 불필요한 무음, 반복 호흡, 문장 뒤 긴 꼬리를 검사한다. 감정 호흡까지 기계적으로 삭제하지 않는다.
4. 최종 오디오와 영상 길이 차이는 `round(TTS 초 × fps)` 기준 최대 1프레임으로 맞춘다.
5. 모든 문장이 자기 장면을 소유하며 문장이 끝나기 전에 다음 의미 장면이 나오지 않는지 검사한다.
6. 모션·줌·그래픽은 발화 문구의 의미 대상에 붙는다. 설명할 수 없는 장식 모션은 삭제한다.
7. 검은 화면, 잘린 자막, 틀린 숫자·영문·한글, 깨진 폰트, 음원 클리핑을 검사한다.
8. 생성·재현 영상이면 YouTube의 altered/synthetic content 항목을 사실대로 `Yes`로 설정한다.
9. Flow·외부 생성형 AI로 만든 사실적 의료·역사 재현 장면이 하나라도 있으면 업로드 `Attributes → AI use`를 `Yes`로 잠그고, 설명에 `일부 장면은 역사·의학 자료를 바탕으로 AI로 재현했습니다.`를 넣는다.
10. Shorts는 승인된 9:16 썸네일을 최종 영상 `t=0.000초`의 실제 첫 프레임으로 넣고 업로드 때 해당 프레임을 선택한다. longform은 승인된 16:9 썸네일 파일을 별도로 업로드하되 첫 장면과 같은 피사체·질문을 유지한다.
11. 첫 2초에 검은 화면·로고·별도 타이틀·페이드 인·무관한 장면 전환이 없어야 한다. 썸네일의 주 피사체와 첫 후킹 문장의 의미가 그대로 움직여야 한다.
12. 최종 QA에 `thumbnail_sha256`, 첫 프레임 캡처 해시, 시각 일치 판정, 첫 후킹 문장 ID, 첫 2초 불연속 컷 수를 기록한다.
13. 문장별 TTS 소유 구간과 장면 시작·끝, 자막 페이지 시작·끝을 프레임 단위로 대조한다. 장면·자막 오차는 각각 최대 1프레임, 조기 장면 전환·누락 단어·중복 자막은 0건이어야 한다.
14. 불일치가 있으면 업로드 파일을 임시로라도 사용하지 않는다. 최종 강제정렬에서 장면·자막 타임라인 재생성→클립 길이 보정→재렌더→전체 재생→검증기 재실행 순서로 수정한다.
15. 최종 MP4·TTS·정렬·자막 해시가 일치하는 `final-sync.lock.json`이 `PASS`가 아니면 비공개 업로드도 금지한다.

## 공개 순서

1. 최종 해시가 잠기고 `final-sync.lock.json=PASS`, frame-zero 썸네일 잠금이 통과한 MP4만 비공개로 업로드한다.
2. HD 처리, 전체 재생, 음성, 자막, 제목, 설명, 해시태그, 첫 프레임, 대상 채널을 검수한다.
3. 아동용이 아닌 일반 교육 콘텐츠로 정확히 설정한다.
4. `AI use=Yes`와 설명의 AI 재현 고지를 다시 확인한다.
5. YouTube Studio에서 선택된 썸네일 미리보기가 승인 frame-zero와 같은지 확인하고 `thumbnail-selection.lock.json=PASS`를 만든다. 확인할 수 없으면 예약을 누르지 않는다.
6. 승인된 운영 슬롯은 오전편 10:00 비공개 업로드→11:00 공개, 오후편 18:00 비공개 업로드→19:00 공개다. 검수가 늦으면 미완성 상태로 공개하지 않고 해당 편을 차단한다.
7. 예약 뒤 video ID, 비공개 업로드 시각, 처리 확인 시각, 공개 예약 시각, canonical URL, idempotency key, AI use 선택값, 썸네일 선택 프레임과 미리보기 캡처 해시를 release lock에 기록한다.
8. 공개 시각 이후 canonical URL과 실제 공개 상태, 공개 페이지의 썸네일 표시를 다시 확인한다.

## 조건부 쿠팡·YouTube Shopping

- 실제 관련 상품이 있는 편만 [commerce-routing.md](commerce-routing.md)를 읽고 `commerce_route`를 만든다.
- 정확한 상품·옵션·판매자·현재 가격·재고·배송·제휴 링크·고지 문구·대상 채널이 잠기지 않으면 링크와 상품 태그를 넣지 않는다.
- 제휴 링크가 있으면 설명 첫부분에 `[광고]`와 최신 공식 쿠팡 파트너스 고지를 두고 YouTube의 `유료 프로모션` 항목을 사실대로 체크한다.
- YouTube Shopping 상품 태그는 채널과 상품이 Studio에서 실제로 자격을 가진 경우만 쓴다. 외부 쿠팡 링크를 붙였다고 Shopping 태그가 자동으로 생기는 것으로 간주하지 않는다.
- 본편 대본에 상품 CTA를 자동 삽입하지 않는다. 별도 승인된 경우에만 TTS·장면·자막·상품 주장 전체를 다시 잠근다.
- 공개 확인 때 설명의 제휴 고지·링크, 유료 프로모션 표시, 상품 태그, 정확한 상품 일치를 함께 확인한다.
