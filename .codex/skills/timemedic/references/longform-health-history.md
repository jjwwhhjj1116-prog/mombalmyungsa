# 몸의 발명사 8~10분 롱폼 집필 계약

## 1. 길이부터 늘리지 않는다

롱폼은 긴 쇼츠가 아니다. `어떻게 해결했나`뿐 아니라 `그 해결 뒤에 무슨 대가와 논쟁이 남았나`까지 답하는 두 번째 이야기다.

다음 다섯 관문 중 네 개 이상을 통과하고, 1번과 2번은 반드시 포함해야 한다.

1. `실패의 사다리`: 성공 전 시도·기각안이 최소 두 개 있고 각각 왜 막혔는지 의학적·제도적·물리적으로 설명할 수 있다.
2. `해결의 대가`: 해결책이 부작용·비용·불평등·내성·오진·새 위험 가운데 하나를 실제로 낳았다.
3. `현재 논쟁`: 지금도 의료계·공중보건·사회가 판단을 달리하는 쟁점이 있다.
4. `최근 사건`: 최근 3년 안의 지침 변경·연구·유행·안전 이슈가 있다.
5. `숨은 절반`: 사람들이 아는 한 명·한 제품·한 발견보다 더 중요한 시스템·팀·후속 개선이 있다.

네 개를 못 채우면 정보를 반복해 8분을 만들지 않는다. 180초 이하의 독립 쇼츠로 다시 편집하거나, 서로 다른 질문을 가진 별도 편으로 나눈다.

## 2. 실제 TTS 길이 라우팅

- 승인 대본 전체를 고정 보이스와 설정으로 연속 합성한 실제 TTS가 `180.000초 이하`면 `9:16 Shorts`다.
- `180.000초 초과 480.000초 미만`이면 바로 제작하지 않는다. 롱폼 관문을 통과한 소재는 대본을 `8~10분`으로 확장해 다시 검수·승인하고, 통과하지 못한 소재는 쇼츠로 되돌린다.
- 최종 TTS가 `480.000~600.000초`이면 `16:9 longform`으로 잠근다.
- `600.000초 초과`면 반복과 우회 설명을 걷어내 8~10분으로 다시 편집한다. 중요한 증거를 자르는 대신 질문을 다음 편으로 분리할 수 있다.
- 글자 수는 추정치일 뿐이다. 몸의 발명사 실측 `9.35자/초`를 쓰면 8~10분은 약 `4,488~5,610자`지만, 최종 판정은 실제 TTS 길이만 사용한다.
- 3~7분짜리 중간 길이를 새로 기획하지 않는다. 이미 승인·제작을 마친 과거 편은 명시적인 `legacy_intermediate_longform_exception`으로만 보존한다.

## 3. 14블록 구조

각 블록은 보통 30~55초, 최대 65초다. 해답은 전체의 약 55% 지점에 오고, 그 뒤 내용이 전체의 최소 24% 남아야 한다.

| 블록 | 기능 | 몸의 발명사 작성 규칙 |
|---|---|---|
| 훅 | 현재 모순 + 2단 질문 | 익숙한 치료·행동을 낯설게 만들고 `어떻게 가능했나`와 `그 뒤 무엇이 달라졌나`를 함께 묻는다. 과장 뒤에는 즉시 한정·정정을 붙인다. |
| Ch1 | 문제의 본질 | 몸·병원체·도구·제도 중 핵심 원리 하나를 초등학생 비유로 번역한다. 뒤에서 다시 회수할 개념을 심는다. |
| Ch2 | 시도 1과 실패 | 당시 사람이 바보처럼 보이지 않게, 무엇은 해결했지만 핵심은 왜 못 건드렸는지 말한다. |
| Ch3 | 시도 2와 악화 | 시청자가 떠올릴 반론을 먼저 인정한 뒤, 실제로 했을 때 왜 더 나빠졌는지 빠르게 보여준다. |
| Ch4 | 본격 개입 | 구체 행동·인물 역할·규모·숫자를 보여주고 숫자를 생활 장면으로 번역한다. |
| Ch5 | 새 난관 | 해결 때문에 생긴 새 부작용이나 양쪽 손실을 드러낸다. 검증된 이중 손실이면 막힘 시그니처를 정확히 한 번 쓴다. |
| Ch6 | 기각된 대안 | 가장 그럴듯한 다른 방법을 실제 사례와 함께 인정하고, Ch1의 원리를 회수해 왜 못 쓰는지 설명한다. |
| Ch7 | 질문 전환과 작동 해부 | `그래서, 사람을 살리는 질문부터 뒤집습니다.` 뒤에 새 질문·구체 행동을 둔다. 몸·병원체·도구·제도의 원인→전달→반응 사슬을 단면·분해·흐름으로 해부한다. |
| Ch8 | 확장과 역할 분담 | 두 번째 해결책이나 후속 팀이 첫 해결책의 빈틈을 어떻게 메웠는지 보여준다. |
| Ch9 | 숨은 절반 | 대중이 아는 주인공 뒤의 시스템·생산·교육·감시·표준화를 꺼낸다. |
| Ch10 | 대가 | 해결책의 부작용과 실패를 먼저 인정한다. 숫자는 사람이 겪는 행동으로 바꾼다. |
| Ch11 | 현재 논쟁 | 자기 주장에 불리한 가장 강한 근거도 숨기지 않고, 왜 아직 결론이 안 났는지 말한다. |
| Ch12 | 최근 사건 | 최근 3년 안의 지침·연구·유행·기술 변화를 넣어 과거 이야기를 현재형으로 바꾼다. |
| 회수 | 두 질문의 답 | 훅의 두 질문을 순서대로 답하고 새 사실 없이 현재 장면의 의미를 바꾼 뒤 고정 엔딩으로 끝낸다. |

## 4. 체류시간 장치

- 시청자 반론을 최소 두 번 먼저 말한다. `그럼 그냥 A하면 되지 않냐고요? 실제로 했습니다.` 뒤에 실패 원리를 붙인다.
- 자기 논지에 불리한 사실을 최소 두 번 먼저 인정한다. 과장보다 신뢰가 8분을 버티게 한다.
- Ch1에서 설명한 개념 하나는 Ch6 이후에 문자 그대로 또는 쉬운 변주로 회수한다.
- 모든 챕터 마지막은 다음 챕터의 원인·질문·미완성 행동을 열어 둔다. 주제를 새로 시작하는 접속사는 금지한다.
- 낯선 인물은 `역할·시대/장소·문제와의 관계 → 이름 → 실제 행동` 순서로 소개한다.
- 발견을 한 사람, 실용화한 팀, 대량 보급·표준화한 체계를 한 명의 천재로 합치지 않는다.

## 5. 롱폼에서 쇼츠 파생

롱폼 완성 후에는 같은 주제의 독립 쇼츠를 만들 수 있다.

- 롱폼의 승인 문장과 실제 TTS 구간을 그대로 발췌하면 새 유료 TTS와 대본 재승인 없이 파생 가능하다.
- 문장을 재작성하거나 새 주장·새 TTS를 추가하면 별도 대본 검수와 사용자 승인을 다시 받는다.
- 쇼츠는 `variant_id`, `idempotency_key`, 9:16 썸네일, frame-zero, 최종 QA, 공개 URL을 롱폼과 별도로 가진다.
- 쇼츠는 롱폼 예고편이 아니라 `훅 → 모순 → 양쪽 손실 → 질문 전환 → 한 해결 → 의미`가 스스로 닫히는 독립 이야기여야 한다.
- 롱폼과 쇼츠의 같은 미디어를 두 번 올린 것으로 오인하지 않도록 제목·첫 3초·설명 약속을 각각 잠근다.

## 6. 최종 롱폼 검사

- 다섯 관문 중 네 개 이상이며 실패 사다리와 해결의 대가가 모두 있는가.
- 질문이 `어떻게`와 `그 뒤 어떻게 됐나`의 두 층인가.
- 성공 전 실패·기각안이 두 개 이상인가.
- 해답 뒤 분량이 최소 24%인가.
- 현재 논쟁과 최근 3년 사건이 출처 ID에 잠겼는가.
- 각 블록이 65초를 넘지 않는가.
- 최종 TTS가 480~600초인가.
- 시대·지역·제품 고증 카드를 통과했는가.

하나라도 아니오면 스토리보드와 Flow 생성으로 넘기지 않는다.
